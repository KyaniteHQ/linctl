## Guarded writes

Each command below changes Linear. Before the change, linctl resolves the target from the live OAuth credential and compares it with the target pinned in `.linctl.toml`. A mismatch is a hard stop: linctl makes no change, prints `{"error_code":"TARGET_MISMATCH"}`, and exits non-zero. No flag makes a mismatched write proceed.

Two notes appear in the tables:

- **org-wide** — the command has an `--org-wide` flag. The entity has no team, so the comparison is organization-only. The flag makes the blast radius explicit. It is not a bypass, and a mismatch is still a hard stop.
- **irreversible** — linctl cannot undo the command. Every other removal archives or retires the entity, and you can restore it.
